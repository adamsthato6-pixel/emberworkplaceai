# Work Buddy AI

Build a fully functional, responsive web app named “AI Workplace Productivity Assistant.” Make it visually distinctive and premium, avoiding generic SaaS-dashboard styling. Create a clean professional dashboard with sidebar navigation, card layout, and interactive UI. Include these polished AI feature workspaces: Smart Email Generator (tone + audience controls), Meeting Notes Summarizer (key points, actions, deadlines), AI Task Planner (prioritization + schedule), AI Research Assistant (insights + summaries), and an AI Chatbot Interface. Implement structured prompt engineering for each feature, with professional clear generated outputs, useful preset examples, loading states, editable inputs, and responsive design. Include the disclaimer text exactly: “AI-generated content may require human review”. Since it is a prototype, make AI interactions feel functional with local simulated outputs/loading without requiring API credentials. Give it a unique, beautiful visual direction with memorable details and cohesive UX. Verify the app builds successfully.
